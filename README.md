# Saikrishna & Kavya — Free Wedding Invitation

A mobile-first South Indian temple-style wedding invitation website for:

- Groom: Saikrishna
- Bride: Kavya
- Wedding: 15 November 2026
- Venue: VASAVI KALYANAMAMDAPAM, Vemulawada, Road, Kamareddy - Sircilla Rd, Sircilla, Telangana 505301

## Files

- `index.html` — page structure and wedding text
- `styles.css` — traditional cream/gold/maroon design and animations
- `assets/` — add your own photos and optional music here

## Add your photos

Put these files inside `assets/`:

- `groom.jpg`
- `bride.jpg`
- `photo-1.jpg`
- `photo-2.jpg`
- `photo-3.jpg`
- `photo-4.jpg`
- `photo-5.jpg`

You can use fewer photos; the remaining gallery tiles will show an add-photo placeholder.

## Add music

Put a legally obtained MP3 file at:

`assets/music.mp3`

The site does NOT autoplay music. Guests tap the Music button to start or pause it.

## Publish free with GitHub Pages

1. Create a GitHub account.
2. Create a public repository, for example `saikrishna-kavya-wedding`.
3. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder.
4. Repository Settings → Pages.
5. Under Build and deployment, choose `Deploy from a branch`.
6. Select branch `main` and folder `/ (root)`.
7. Save and wait for deployment.
8. Your site will be available at a URL similar to:
   `https://YOUR-USERNAME.github.io/saikrishna-kavya-wedding/`

## Important

The site intentionally does not invent a wedding time, additional functions, family names, or other details that were not supplied.

RSVP is intentionally not included in this version.
